## INAV 10.0.0-RC1 Available

**INAV 10.0 is a major release** introducing significant new features — terrain-following navigation, DroneCAN support, VTOL auto-transition, and more. This Release Candidate is for pilots who want to test the new features early. **We're also planning a final 9.1.x bug-fix release in about 4-6 weeks** for anyone who wants maximum reliability without new-feature growing pains.

**Since 9.1.0/9.1.1:** ~79 fixes and ~134 features/enhancements in firmware, ~23 fixes and ~60 in Configurator.

### What's New

1. **Terrain-Following Navigation**
   Fly at a set height above the ground using preloaded terrain data — powers the new Terrain AGL Hold mode, generated via Configurator's new Map Generator tab

2. **DroneCAN Support**
   CAN-bus peripherals with a dedicated Configurator tab for setup and diagnostics

3. **VTOL Auto Transition**
   Airspeed-based automatic transition with stabilization and lift-control smoothing

4. **Fixed-Wing Auto Speed Mode & Coordinated WP Turns**
   Hold a chosen airspeed, and fly waypoint turns as proper coordinated arcs

5. **Mission Control Upgrades**
   Grid Survey Pattern Generator, Google location/weather integration, 3D terrain view, waypoint list selector

### Upgrading from 9.x — Read First
**Full Chip Erase required.** Use Configurator's **Backup Config** before flashing and **Restore Config** after — that's what runs automatic settings migration. (Pasting `diff all` into the CLI does *not* migrate settings.) Full details, including removed/renamed settings: see the release notes below.
