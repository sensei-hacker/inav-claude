Page  392: 19.1 DAC introduction
Page  392: The DAC uses a 12-bit digital input to generate an analog output between 0 and reference voltage. The
Page  392: digital part of the DAC can be configured in 8-bit or 12-bit mode and can be used in conjunction with the
Page  392: DMA. It supports left or right alignment in a single /dual DAC modes. It has two output channels, DAC1
Page  392: and DCA2, with its own converter each. Each DAC1/DAC2 can be converted independently or
Page  392: simultaneously in dual DAC mode. The input reference voltage VREF+ makes conversion more accuracy.
