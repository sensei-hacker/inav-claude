Page  358: 18 Analog-to-digital converter (ADC)
Page  358: 18.1 ADC introduction
Page  358: The ADC is a peripheral that converts an analog input signal into a 12-bit/10-bit/8-bit/6-bit digital signal.
Page  358: Its sampling rate is as high as 5.33 MSPS. Each ADC has up to 19 channels (internal + external) for
Page  358: sampling and conversion, totaling 24 external channel sources for three ADCs.
Page  358: 18.2 ADC main features
Page  358:  Self-calibration time: 205 ADC clock cycles
Page  358:  ADC conversion time
Page  358: − Fast channel: ADC conversion time is 0.1875 μs at 80 MHz in 12-bit resolution (5.33MSps)
Page  358: − Slow channel: ADC conversion time is 0.2375 μs at 80 MHz in 12-bit resolution (4.21MSps)
Page  358: − Fast channel: ADC conversion time is 0.1126 μs at 80 MHz in 6-bit resolution (8.88MSps)
Page  358: − Slow channel: ADC conversion time is 0.1626 μs at 80 MHz in 6-bit resolution (6.15MSps)
Page  358:  ADC supply requirement: Refer to AT32F435/437 datasheet for more information
Page  358:  ADC input range: VREF- ≤ VIN ≤ VREF+
Page  358:    ADC master/slave modes
Page  358:    Master/slave shift mode with programmable timing shift length between ADCs
